HOW TO APPLY TO THE EXISTING REPOSITORY
1. Download and extract this package.
2. Copy index.html, styles.css and script.js into the root of your existing emyDahliaEmpire repository, replacing the old versions.
3. Copy the assets folder into the repository root.
4. Keep the existing four book cover images in the repository root: buku1.jpeg, buku2.jpeg, buku3.jpeg and buku4.jpeg. The redesigned page references these filenames.
5. Preview locally by opening index.html or using VS Code Live Server.
6. Commit and push the changes to GitHub.
